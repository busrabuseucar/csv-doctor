# CV için örnek metin

CV’nin **Projeler** bölümüne ekle. Bu metin uygulamanın doğrulanmış yeteneklerini anlatır; bireysel katkı ve sahiplik konusunda gerçekte yaptığın işi ayrıca belirt.

**CSV Doctor — CSV Veri Kalitesi ve Temizleme Aracı**  
Kişisel proje · Yapay zekâ destekli geliştirme  
JavaScript (ES Modules), Web Workers, Node.js, CSV, GitHub Actions

- CSV dosyalarında eksik hücreleri, yinelenen kayıtları ve tür tutarsızlıklarını inceleyen; temizleme önizlemesi ile CSV/JSON çıktıları sunan MVP.
- Tarayıcı ve komut satırında ortak veri işleme motoru; dosyayı sunucuya yüklemeden çalışma, orijinal veriyi koruma ve elektronik tablo formül başlangıçlarını önekleme.
- CSV ayrıştırma, veri koruma, temizlik kuralları ve komut satırı davranışları için 28 otomatik test; GitHub Actions kontrol iş akışı.

[GitHub](https://github.com/busrabuseucar/csv-doctor) · [Canlı demo](https://csv-doctor-buse.sleek-brush-8818.chatgpt.site)

CV’yi PDF olarak kaydederken iki bağlantının da tıklanabildiğini kontrol et. Güncel otomatik kontrol durumu deponun Actions sayfasında görülebilir.

Kısa İngilizce sürüm:

**CSV Doctor — CSV Quality & Cleaning Tool**  
Personal project · AI-assisted development  
JavaScript, Web Workers, Node.js, GitHub Actions

- MVP for inspecting missing values, duplicate records and type inconsistencies, with original/cleaned previews and CSV/JSON exports.
- Shared browser and CLI processing engine with local file handling, original-data preservation and spreadsheet formula-prefix protection.
- 28 automated tests covering CSV parsing, cleaning rules, export integrity and CLI behavior; a GitHub Actions verification workflow.

Bu projeyi veri işleme, yazılım geliştirme veya test otomasyonu odaklı başvurularda kullanabilirsin. Katkını açıklarken, gerçekten incelemediğin veya değiştirmediğin kod için bağımsız geliştirme iddiasında bulunma.
